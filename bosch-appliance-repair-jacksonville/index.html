Fault Code Reference

Bosch Dishwasher Showing a Code?

Three codes homeowners ask about most. Try the quick check, and if the code comes back, we find and fix the cause.

E15
Water in the base

The leak safety system has detected water in the base. Check for visible leaks at the door, hoses and inlet, and stop running the dishwasher until the cause is found. We locate the source and clear the fault.

E24
Drain fault

Check the filter at the bottom of the tub and the drain hose for clogs or kinks. If the water still will not drain, the drain pump or check valve may need replacement.

E09
Heating fault

The dishwasher is not heating the water properly. This usually points to a failed heating element or sensor, so the circuit needs to be tested. It is not a reset-and-hope fix.
